## 覆盖的分析难点

- 归属方式：引语前「某某说：」、引语后「……他说」、引语中间插入说话人或动作、连续多轮无标注交替、极短回应（「好。」「姓解？」）。
- 旁白中的引号术语：「哑钟」「文明乘车」「第二杯半价」「咔」等应归旁白。
- 转述对话：第二章电话一段全部是转述，应归旁白。
